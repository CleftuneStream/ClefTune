Highlights

Everything you wanted.
Nothing you didn't.

Music that doesn't stop

Audio plays inside the app, not a browser tab. Close the window and the music keeps going. Bring it back from the tray, menu or Dock.

Starts in ~0.5 s

A lean, single-client stream lookup. Upcoming songs, and the one under your pointer, are prepared ahead, so they start almost instantly.

Lyrics, properly

Time-synced from LRCLIB, YouTube Music and KuGou, with word-by-word highlighting, click-to-seek and per-song timing nudges.

Popular first

Search puts the songs people actually play on top, ranked by play count, while keeping results that match what you typed.

Safe sign-in

Sign in to Google in your own browser, never an embedded window. ClefTune picks the login up automatically. Optional, always.

Zero setup

Every installer brings its own Python, FFmpeg and JavaScript runtime. No admin rights, nothing to install first.

How it works

Two programs.
One very stubborn song.

The UI is just a remote control. The Python core does the real work and keeps running until you Quit, which is why closing the window never stops the music.

Interface Plain HTML / CSS / JS Window add-on or any browser
JSON-RPC + SSE · 127.0.0.1 · per-launch token
ClefTune core · Python Queue · Streams · Lyrics · Library FFmpeg + miniaudio native engine
metadata + audio only, no ad system involved
Sources YouTube Music · LRCLIB · KuGou via yt-dlp & ytmusicapi
